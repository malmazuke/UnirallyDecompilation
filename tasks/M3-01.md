## Outcome and boundaries

Extend the human-readable native Crawler/DRAGSTER simulation from M2's frame
2999 boundary through both frozen M3-00 complete-race paths. Match the observed
per-rider finish flags, the 240-update post-player delay, neutral-axis override,
race timer and the future-affecting stored time/outcome/transition state needed
to continue deterministically. Revise canonical state explicitly, with
fresh-process save/restore checks around the finish boundaries.

The first action is a bounded reference experiment for the result-screen stored
time/outcome fields that M3-00 deliberately left unknown. Freeze its fields and
expected projections before native code computes them. If another
future-affecting dependency is found, record and freeze the smallest prerequisite
rather than injecting captured state or inventing a plausible rule.

Not in scope: native graphics, rider-frame mapping, BG1 gather, SDL/live input,
audio, menus, complete trick support, another track/rider/mode or M3 acceptance.
Those remain M3-02 through M3-04. Do not execute the original CPU or consume
per-frame reference values in the native runner.
