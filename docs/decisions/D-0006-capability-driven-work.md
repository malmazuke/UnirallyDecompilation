## Reason and decision

M4-05 through M4-11 recovered useful dependencies in the same 51-frame window,
but each paid a separate planning, worker, review and integration cycle. The
accepted result is still reference research. This suggests excessive task
fragmentation; it does not prove a model throughput or cost advantage.

M4-12 was assigned one native capability: autonomous two-rider
ZOOM ZOO movement in a declared expanded domain. The primary Astra/medium agent
owns investigation, native implementation and integration in a sustained context.
Do not delegate the core problem to a routine worker or spawn a separate Astra
planning consultation. Sol/medium independently reviews the candidate automatically.
Model and resource exceptions are defined only in [D-0004](D-0004-model-and-usage-budget.md);
use its M4-13 extension for the next task and its M4-12 section for historical scope.

## Execution

- Keep experiments, functions and commits small. Recover a dependency, implement
  it in native code, compare with the frozen reference, then resolve the first
  divergence. Reuse the accepted Python research as evidence; new Python-only
  evaluators need a concrete diagnostic purpose and a path into native code.
- New coupled producers belong in the same task's dependency/experiment list.
  Split only for independent ownership, a materially different outcome or review
  size/risk; record the reason. A split must not reset usage accounting or turn
  partial captured-state research into acceptance of the native capability.
- First reproduce the short accepted window, then extend into a longer domain
  frozen before implementation tuning. Select experiments to exercise relevant
  writers, state transitions and branches. Preserve negative results; an inert
  input variation alone is insufficient generalization evidence.
- A checkpoint records current native coverage, remaining captured dependencies,
  first divergence, next experiment and usage. Ten-minute checkpoints and
  45-minute reassessments do not end the task, reset its budget or require a
  new agent. Stop an unproductive approach after the existing attempt limit.
- Native code remains readable under D-0003. Preserve exact integer arithmetic,
  ordering, timing and source evidence. Unknown values must not become invented
  rules, zero defaults, replay scripts or later captured-state injections.

## Review and validation

The primary must automatically spawn one fresh Sol/medium review subagent with
an explicit model/effort, isolated checkout of the exact candidate, focused
handoff and no implementation conversation history. Reviewer owns its report
and independent cases; it must not silently fix the implementation. The primary
handles corrections and re-review without asking the user to trigger either.
Use the staged validation policy in [BUILD_AND_VALIDATION](../BUILD_AND_VALIDATION.md#validation-by-stage).
An agent cannot approve its own implementation. If review is unavailable,
checkpoint as unaccepted rather than silently substituting self-review.

## Assess the trial

Report native exact-match interval and field set, relevant branch coverage,
remaining dynamic captured inputs (zero for acceptance), independently passing
variations/restores, review findings/fix rounds, measured elapsed time and
account-wide usage delta with the unrelated-work caveat. Research discoveries
are useful intermediate results but cannot satisfy either task's native outcome.

End the trial when its capability is accepted or its resource/access boundary
prevents further work. M4-12 ended at its acceptance; the explicit M4-13
extension above is the next assignment. Do not automatically claim M4-14 or
the rest of M4.
Preserve partial commits and an honest recovery handoff if incomplete. No speed,
completion date or full-game accuracy promise follows from this policy change.

Frozen evidence, ROM/content privacy, independent review, exact integration
checks and verified private-origin synchronization remain required. D-0001--
D-0003 and D-0005 remain in force. Historical task acceptance criteria are not
retroactively changed by this decision.
