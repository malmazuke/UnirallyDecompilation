## Outcome and boundaries

Version replay manifests (scenario ID, ROM/core identity, initial procedure or state sidecar, both controllers' inputs with timing units and injection point, sampled-field schema, regeneration command); compare repeated reference runs; deliberately perturb a known active input (for this ROM, Start at frame 300 of a cold start is known to change work RAM on that frame, R-0002 finding 6) and produce a detectable difference; emit a first-divergence report (frame, prior sample, inputs, field values, the trace window from the samples); fail clearly on missing inputs and on timeout using the existing exit codes. State fields may initially be raw diagnostic ranges of work RAM; no gameplay interpretation.

Not in scope: native game code, gameplay fields (M1), scheduler (M0-05).
