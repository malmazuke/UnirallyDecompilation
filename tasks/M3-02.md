## Outcome and boundaries

Define and implement the deterministic, headless presentation boundary for the
accepted CRAWLER/DRAGSTER slice. Recover the rider pose-to-frame mapping and the
BG1 column gather from decoded track data, add the minimum background, rider,
HUD and stable-result assets to a versioned Classic pack profile behind logical
IDs, and render reference-checkable native frames without ROM offsets or a ROM
at runtime.

SDL windowing, live controls and PAL scheduling belong to M3-03. Audio, menus,
other tracks/riders, high-resolution replacements, editor/mod APIs and public
distribution are out of scope. Do not change accepted gameplay state or its
serialization.

## Acceptance

- Freeze presentation fields, sampling phase, logical IDs and expected frame
  cases before native rendering changes.
- Reproduce the BG1 tile-map column gather from the decoded `$7F` block rather
  than replaying the original upload sequence.
- Map the accepted semantic rider pose/orientation state to the original rider
  frame/tile data for preregistered race, finish-delay and result cases.
- Extend extraction deterministically; the new pack remains exact-ROM gated,
  atomic, inspectable, mutation-tested and contains no tracked original bytes.
- Render the minimum BG/rider/HUD/result composition headlessly and compare
  native-resolution output against frozen reference frames with explicit,
  predeclared omissions or per-region mismatch limits.
- Prove gameplay canonical hashes are unchanged with presentation enabled and
  that the renderer runs from the validated pack with the ROM absent.
- Add authored ROM-free parser/renderer boundary tests; pass debug and
  sanitizer suites, private reference checks, repository hygiene audit and an
  independent withheld frame/corruption review.

## First experiment

Regenerate or reuse the accepted R-0008 port/access evidence for frames 1600,
2000 and 2400. At the frame-1334 load boundary, relate `$0234`, `$0236` and
`$0559` to `$7F:000F + X` and the staged 32-byte BG1 columns, then decode that
region into coordinates. After the shared schema is frozen, trace which sprite
ROM reads/DMA rows are selected by the native pose fields at those frozen
frames. Record observations separately from interpretation.

Only the coordinator marks this task accepted after independent review and
integration evidence.
