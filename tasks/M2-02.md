## Outcome

Prove that the complete native semantic state can be serialized after an update,
loaded by a fresh native process and continued byte-for-byte identically to an
uninterrupted execution. Preserve the accepted M2-01 projections and input/static
content boundaries. Demonstrate a portable, ROM-free continuation check on both
CI platforms as well as exact local checks using the identity-bound M2-01 cases.

## Implementation contract

Add `python3 tools/project.py native restore-check --manifest <case>
--save-frame <N> [--save-frame <N> ...]`. The command must build the normal
`movement_runner`, run one uninterrupted baseline, then for each distinct save
frame run a prefix in one process, persist its canonical final state, and resume
the suffix in another fresh process. The combined projections and every
canonical state from the resumed suffix must equal the uninterrupted baseline.
The baseline must still match the frozen reference. Reports record state width,
saved-state SHA-256, suffix-series/final hashes, process count and boundaries.

Only seed, static content and controller masks may enter a native process. A
saved state is accepted only if its magic, exact333-byte width and embedded frame
match the boundary. All case/runtime/content hashes are checked before and after
execution. Fresh artifact directories and bounded timeouts retain the native
comparison command's failure taxonomy.

Add ROM-free authored checks that generate deterministic semantic state/content,
exercise uninterrupted versus split continuation across at least two boundaries,
and pin a platform-independent canonical series hash. Continue rejecting bad
magic, flags, phases, cursors, truncation and trailing bytes; add explicit wrong
width/frame, duplicate/out-of-range boundary, corrupted saved-state and
crash/timeout coverage at the command layer.

state discovered outside the333-byte schema is a real dependency: document its
source and revise the format explicitly rather than injecting captured state.
